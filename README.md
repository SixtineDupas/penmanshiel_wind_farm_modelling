# Penmanshiel Wind-Farm Modelling

Code for dissertation comparing direct and turbine-resolved approaches to wind-farm power prediction using Penmanshiel SCADA data

The analysis compares three feedforward neural-network approaches:

- Model A: direct farm-power prediction
- Model B: turbine wind-speed prediction followed by power-curve conversion
- Model C: direct turbine-power prediction followed by aggregation

See the `notebooks/` folder for the full analysis workflow.

Raw data are available from Zenodo:

https://doi.org/10.5281/zenodo.16807304
